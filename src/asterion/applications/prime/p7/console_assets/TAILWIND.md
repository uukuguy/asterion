# Vendored Tailwind CSS

`tailwind.css` is generated by Tailwind CSS 3.4.17 (MIT).
The distribution license is in `TAILWIND-LICENSE.txt`.
Source and installation reference: https://v3.tailwindcss.com/docs/installation

The shipped HTML embeds this static CSS. Export and viewing require neither npm
nor a build step. There is no CDN or browser Tailwind compiler.

Maintainers can regenerate the file after changing utility classes:

```sh
printf '@tailwind base;\n@tailwind components;\n@tailwind utilities;\n' > /tmp/p7-console-tailwind.css
npx --yes tailwindcss@3.4.17 \
  --input /tmp/p7-console-tailwind.css \
  --content './src/asterion/applications/prime/p7/console_assets/*.{html,js}' \
  --output src/asterion/applications/prime/p7/console_assets/tailwind.css --minify
```

The canvas palette comes from the operator-installed arc-agi 0.9.9
`arc_agi/rendering.py:COLOR_MAP`; it is the 16-color ARC-AGI-3 palette.
