# P7 transition evidence and autonomous research design

User approved this design after the Task21 death RESET analysis. Scope is implementation and verification; a fresh BP35 comparison is separate.

## Problem and evidence

Task21 passed six BP35 levels but three deaths followed automatic vertical movement. L2 introduced an unknown hazard; L3 actor-authored sampling collapsed purple open/closed shapes; L4 did not apply previously seen upper danger to the current standing column. Raw host evidence is already lossless. Prime is not responsible for deciding game safety or authoring a game model.

## Selected design

Retain Prime execution/memory and all registered tools. P7 adds one read-only `r.transition(sequence)` function to its existing IPython research module. It combines the actual committed action, exact before/after observation references, recorded after state/level count, and animation descriptor for that after observation. No frames are embedded; existing `r.frame(ref['sequence'])` and `r.animation(after_ref,start,limit)` read evidence explicitly. The animation contains only SDK-recorded frames and does not promise complete physical motion.

The sequence is a current-run paid journal sequence, integer >=1. Reject zero, bool, negative, absent, future, or uncommitted effects. References preserve run/attempt/sequence/hash and the actual level of each observation, including RESET and level changes. Results are detached, bounded, and authenticated through the existing bridge. Reading never acts or reconstructs a missing result.

P7's autonomous prompt documents this research path and the true signatures of existing helpers. It describes optional actor-authored state/transition models and historical testing, preserving observed distinctions and unknown bounds. It does not prescribe a BP35 rule, route, color meaning, BFS, mandatory model certificate, per-step prediction or note update.

NOTES remain free text and optional. Guidance explains that reusable mechanism knowledge can survive level/RESET boundaries while coordinates, current pose and kernel objects need rechecking. Useful notes can retain applicability, consequences, counterexamples and evidence; no new required schema or admission condition is introduced.

## Ownership and boundaries

- Generic Prime owns persistent IPython, archives, model interaction, memory delivery, exact tool results, cancellation and budgets. No generic module change is required by this design.
- P7 owns the ARC-specific committed evidence adapter and research description.
- The actor owns interpretation, program construction, probes, route selection and memory content.

This is a data/access and research-description change. It cannot automatically detect all information loss in arbitrary actor Python, ensure a correct learned model, or prove a lower death rate.

## Verification

Targeted unittest checks actual runtime journal/observations, exact references, RESET/level changes, animation pagination, immutable results, invalid/unresolved reads and lack of side effects. Real persistent worker import verifies the generated module interface. Existing autonomous admission tests protect optional notes/predictions. Run related Python suites, lint/docs and promotion checks; verify the packaged path with bounded r11l L1 witness under repository deployment rules. No extra BP35 trial, game-specific hint or replay authority is granted.
