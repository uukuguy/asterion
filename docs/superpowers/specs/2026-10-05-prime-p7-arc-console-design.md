# ARC-AGI-3 P7 单 HTML 关卡控制台设计

## 状态

已获用户批准，进入实现计划前的设计记录阶段。

## 目标

提供一个不依赖构建工具、网络和本地服务的单 HTML 应用，用于查看和回放一次 ARC-AGI-3 P7 运行。

页面的主视图是当前游戏关卡。页面必须同时展示：

- ARC-AGI-3 多关卡进度；
- 当前关卡的游戏画面；
- 稳定游戏认知，也就是给 P7 规划使用的世界地图文字；
- P7 的可审计决策过程；
- 游戏动作和动作结果；
- 认知更新与关卡权威状态。

HTML 文件打开后即可工作。所有 CSS、JavaScript 和运行数据都内嵌在同一文件中。

## 非目标

- 不在浏览器中运行 P7 模型；
- 不在浏览器中授权游戏动作；
- 不显示模型私有的隐藏思维链或原始 provider payload；
- 不引入新的通用 runtime、工具注册或执行授权机制；
- 第一版不合并多个独立运行作为长期统计数据库；
- 第一版不要求实时连接正在运行的进程。

## 用户和主要流程

用户打开导出的 HTML 后：

1. 在左侧看到本次运行的游戏和关卡列表。
2. 选择一个关卡。
3. 中央查看该关卡当前帧。
4. 右侧阅读稳定游戏认知。
5. 在时间轴上拖动或点击播放，观察每个动作造成的画面变化。
6. 在下方面板查看对应的 P7 决策信号、动作结果和认知变化。
7. 在过关、失败或运行中状态之间切换，确认权威回执。

“P7 决策”是过程证据，不是动作授权。页面中的动作按钮只用于回放和定位，不执行新动作。

## 页面布局

### 顶部状态栏

显示：

- 项目：ARC-AGI-3；
- 游戏 ID；
- 运行 ID；
- 当前关卡 / 总关卡；
- 已完成关卡数；
- 运行状态；
- 更新时间或快照时间。

状态颜色只用于有限状态：

- 绿色：已过关；
- 蓝色：运行中或可继续；
- 橙色：等待或信息不足；
- 红色：失败；
- 灰色：未运行。

### 左侧关卡管理

每个关卡条目显示：

- 关卡序号；
- 状态；
- 动作数；
- 是否有最终回执；
- 是否有可回放帧。

点击关卡后，中央、右侧和下方内容同步切换。没有数据的关卡必须显示明确的空状态，不用伪造画面或认知。

### 中央关卡画面

中央区域显示当前关卡的网格帧：

- 以网格或像素矩阵渲染；
- 保持颜色值与原始游戏观察一致；
- 适配窗口大小，但不改变格子比例；
- 当前可控对象和最近变化区域有轻量高亮；
- 动作前后帧可并排或叠化比较；
- 无帧时显示“当前关卡没有可回放画面”。

时间轴控件包括：

- 当前帧 / 总帧；
- 拖动滑块；
- 播放 / 暂停；
- 单步前进；
- 单步后退；
- 播放速度；
- 跳到上一个动作；
- 跳到下一个动作。

播放只改变展示状态，不改变原始数据。

### 右侧稳定游戏认知

稳定认知是一份逐步补全的玩法介绍，不是认知日志列表。显示顺序固定：

1. 游戏类型；
2. 画面物件；
3. 动作操作；
4. 游戏规则；
5. 过关条件；
6. 当前玩法；
7. 最近一次稳定更新。

每个部分使用短句。优先显示已确认事实。高置信推断必须单独标记为“规划推断”，不能混入确定事实。尚未确定的内容显示为“尚未确定”，不能写成游戏规则。

稳定认知来源于已确认世界模型和语义报告。重复句子在导出阶段去重，同类内容在展示阶段压缩成连续文本。底层认知记录仍保留在快照中，并可以在“认知更新”面板中按事件查看。

### 下方过程面板

过程面板提供三个视图。

#### P7 决策

按时间顺序显示每个决策轮次：

- 轮次；
- 当前观察；
- 规划目标；
- 使用的稳定认知或世界模型依据；
- 选择的动作；
- 动作结果；
- 下一步判断；
- 决策信号来源和时间。

只显示可审计的决策元数据和有限自然语言摘要。不得将原始 prompt、完整模型响应、凭据或私有 provider 数据嵌入 HTML。

#### 游戏动作

每个动作显示：

- 动作名称；
- 序号；
- 动作前后帧；
- 位置或边界变化；
- 是否移动；
- 是否受阻；
- 关卡数变化；
- 是否出现 WIN；
- 对应的 P7 决策轮次。

动作结果与中央时间轴双向联动。

#### 认知更新

显示认知事件：

- 事件时间和轮次；
- 新确认事实；
- 新否定事实；
- 新增规划推断；
- 关键假说压缩或互斥关系变化；
- 稳定游戏认知更新前后摘要。

只把能改变游戏描述或规划选择的事件放在主列表。完整底层记录保存在快照的可查询数据中，不在主画面一次性展开。

## 快照数据模型

HTML 内嵌一个 JSON 对象：

    window.__ASTERION_STATE__ = {
      schema: "asterion.arc-agi3-p7-console/v1",
      generated_at: "...",
      run: {
        run_id: "...",
        game_id: "...",
        strategy: "...",
        status: "running|successful|unsuccessful|incomplete",
        target_level: 1,
        completed_level_count: 0,
        win_levels: 6
      },
      levels: [
        {
          level: 1,
          status: "...",
          initial_frame: {...},
          frames: [...],
          actions: [...],
          cognition: {
            stable_guide: {
              game_type: [...],
              objects: [...],
              controls: [...],
              rules: [...],
              success: [...],
              play: [...]
            },
            world_map_facts: [...],
            hypothesis_summary: {...},
            updates: [...]
          },
          decisions: [...],
          receipt: {...}
        }
      ],
      indexes: {
        frame_by_id: {...},
        action_by_frame: {...},
        decision_by_action: {...}
      }
    };

字段要求：

- 快照必须包含明确 schema 版本；
- 原始内容导出前必须做大小限制；
- 稳定认知、动作、决策和回执使用独立数组；
- 底层记录只保留必要的审计字段；
- 私有绝对路径、凭据、完整 prompt 和 provider payload 不得导出；
- 缺失数据用空数组或显式状态表示，不用隐式推断。

帧数据可以使用颜色矩阵或压缩后的 JSON 网格。若现有记录中包含图像文件，则导出器将其转换为 data URL 并嵌入；不得依赖外部文件路径。

## 导出和资源方案

增加一个应用级导出入口，读取现有 P7 私有运行证据并生成 HTML：

- 读取运行摘要、轨迹、录制帧、认知快照和回执；
- 统一转换为上述快照；
- 使用固定 HTML 模板；
- 把 Tailwind 的实际使用子集内嵌到 style；
- 把原生 JavaScript 内嵌到 script；
- 把序列化快照内嵌到 script type="application/json"；
- 输出文件名默认为 p7-console-<run_id>.html；
- 允许显式指定输出路径。

这里的 Tailwind 仅作为样式实现方式。生成结果不得通过 CDN、远程字体、外部图片或外部脚本获得运行时依赖。

## 交互和动画规则

- 动画由帧索引和动作事件驱动；
- 播放时每个动作至少显示起始帧、过渡帧（如有）和结算帧；
- 动作切换时同步更新右侧稳定认知的“最近更新”和下方过程面板；
- 时间轴拖动不会自动改变选择的关卡；
- 键盘左右键可以单步，空格可以播放/暂停；
- 用户减少动画或系统偏好减少动态效果时，自动切换为即时跳帧；
- 所有交互控件有可读的文本标签和当前状态。

## 视觉和可读性规则

- 中央关卡画面占主要面积；
- 主文字使用中性颜色；
- 颜色只表达状态、过程类型和重点变化；
- 不把每条底层假说都用彩色文字刷屏；
- 稳定认知使用清晰标题和段落；
- P7 决策、动作、认知更新使用轻量标签；
- 长内容可折叠；
- 页面在窄窗口中改为上下布局；
- 页面不依赖日志等宽排版。

## 安全边界

HTML 是只读回放产物：

- 不含执行新动作的接口；
- 不含网络请求；
- 不解析或执行任意 HTML/脚本；
- 所有用户可见文本经过 HTML 转义；
- 所有 JSON 使用安全序列化；
- CSP 在文档内限制脚本和资源来源；
- 导出器只读取允许的 P7 运行证据目录；
- 任何无法验证身份或格式的数据项被跳过并记录为缺失。

## 验证

实现后至少验证：

1. 生成结果是单个 HTML 文件，不引用外部 CSS、JS、图片或字体。
2. 在无网络环境中打开，页面仍能显示关卡、认知、决策和动作。
3. 关卡切换、时间滑块、播放、单步和动作联动工作。
4. 缺失帧、缺失认知、缺失决策和失败回执显示明确空状态。
5. 稳定游戏认知去重，确定事实、规划推断和未决内容不混淆。
6. 导出内容不包含凭据、原始 prompt、provider payload 或私有绝对路径。
7. 生成器对真实 P7 运行目录工作。
8. 相关 Python 测试、资源打包检查和一次真实 witness 边界验证按项目规定执行。
9. git diff --check 和静态检查通过；已知的既有 make promotion-check 源依赖失败单独记录，不冒充为本功能通过。
