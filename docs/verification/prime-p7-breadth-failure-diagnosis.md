## 已确认的通用缺口

`act_checked` 的 `matched` 只证明**模型自己指定的局部预测**成立，不证明目标有进展。G50T 旧运行 `p7-live-20260925160138-9bcfa33bcf711f1a627838f5` 用满 78 步仍为 0 关；之后的 `p7-live-20260925220255-bedfcba9ad8301dd6c41279b` 在动作 11、25 的稳定帧完全不变，模型仍继续以同类动作试探。后者在 30 步由操作员停止，未封存，只用作诊断，不是可信的失败建议来源。稳定帧无变化不能用状态摘要是否变化判定，因为计时或 SDK 状态可改变摘要而不改变格子。

已实施的同题证据读取修复分别校验封存失败、只重放前缀的封存部分失败、以及执行停滞观察。下一步的游戏无关守卫见 `docs/superpowers/specs/2026-09-26-prime-p7-retry-no-effect-guard-design.md`：无变化时停下已排队动作；同一动作在同关反复无变化后，要求单步预测核对。它只能阻止一类无信息动作消耗，不能识别每题的真正目标或保证通关。
